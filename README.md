# 🌍 Travel Blog Website  

A dynamic travel blog platform built with **PHP** and **MySQL** that allows users to share travel experiences, manage blog posts, and interact with others through comments.  

---

## 🚀 Features  
- 🔐 **User Authentication** – Secure sign-up and login system  
- 📝 **CRUD Operations** – Create, read, update, and delete blog posts  
- 💬 **Comment System** – Engage with blogs through feedback and discussions  
- 🔎 **Search & Filter** – Find posts by location, category, or keywords  
- 📱 **Responsive Design** – Works smoothly on desktop and mobile  
  

---

## 🛠️ Tech Stack  
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Server:** XAMPP
